# NeBrowser 0.1.0 — Technical Preview

Первая доступная сборка NeBrowser на Firefox 153.0.4 для Mac с Apple Silicon.

## Важно

Это **не нотарифицированный массовый релиз**:

- ZIP подписан локальной ad-hoc подписью;
- DMG не подписан;
- macOS Gatekeeper может заблокировать обычный запуск;
- сборка предназначена для проверки продукта до завершения Apple notarization.

Не отключайте системную защиту macOS ради этой версии. Если система блокирует
запуск, дождитесь стабильного нотарифицированного релиза.

## Файлы

- `NeBrowser-0.1.0-firefox-153.0.4-macos-arm64-local-adhoc.zip` — приложение в ZIP;
- `NeBrowser-0.1.0-firefox-153.0.4-macos-arm64-local-unsigned.dmg` — установочный образ;
- `.sha256` — контрольные суммы;
- `NeBrowser-0.1.0-source-overlay.tar.gz` — точный source overlay проекта.

Сборка прошла проверку структуры пакета, bundle identity, архитектуры ARM64,
вложенной ad-hoc подписи ZIP, целостности ZIP и `hdiutil verify` для DMG.
