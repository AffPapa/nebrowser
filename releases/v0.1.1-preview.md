# NeBrowser 0.1.1 — Technical Preview

Обновлённая тестовая сборка NeBrowser на Firefox 153.0.4 для Mac с Apple Silicon.

## Что изменилось

- меньше Mozilla-служб и рекомендательных поверхностей по умолчанию;
- отключены Account/Sync, AI, рекомендации на новой вкладке и лишние кнопки;
- стартовая страница — `https://affpapa.org/`;
- исправлена регрессия ранней lean-сборки: снова работают меню и навигация.

## Важно

Это **не нотарифицированный массовый релиз**:

- ZIP подписан локальной ad-hoc подписью;
- DMG не подписан;
- macOS Gatekeeper может заблокировать обычный запуск;
- сборка предназначена для проверки продукта до завершения Apple notarization.

Не отключайте системную защиту macOS ради этой версии. Если система блокирует
запуск, дождитесь стабильного нотарифицированного релиза.

## Файлы

- `NeBrowser-0.1.1-firefox-153.0.4-macos-arm64-local-adhoc.zip` — приложение в ZIP;
- `NeBrowser-0.1.1-firefox-153.0.4-macos-arm64-local-unsigned.dmg` — установочный образ;
- `.sha256` — контрольные суммы;
- `NeBrowser-0.1.1-source-overlay.tar.gz` — точный source overlay проекта.

Сборка прошла проверку структуры пакета, bundle identity, ARM64 и целостности
архивов. Перед стабильным выпуском обязательны Developer ID, notarization,
stapling и проверка Gatekeeper.
