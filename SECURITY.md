# Security policy

Поддерживается последняя опубликованная версия NeBrowser.

Не раскрывайте уязвимости публично до исправления. Отправьте описание,
минимальный сценарий воспроизведения и затронутую версию через private
vulnerability reporting в GitHub Security Advisories этого репозитория.

Сборки NeBrowser для пользователей считаются настоящими релизами только если
они опубликованы в `AffPapa/nebrowser` GitHub Releases, подписаны Developer ID
Application, нотарифицированы Apple и проходят Gatekeeper.
